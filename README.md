# Свет · setcarlight

Исходный код: [andreykeks/setcarlight](https://github.com/andreykeks/setcarlight).

Веб-приложение для расчёта разметки стены при регулировке ближнего света фар. HTML, CSS и JavaScript; интерфейс на русском, расчёты выполняются в браузере. Серверная часть и база данных не требуются.

Рабочая версия: **https://setcarlight.vercel.app**. Сайт опубликован в Vercel из ветки `main` репозитория GitHub. Предыдущее размещение остановлено.

## Локальный запуск

```sh
cd Web
npm run preview
# Открыть http://127.0.0.1:4173
```

Для локального сервера нужен Python 3, для проверок — Node.js 22+. Установка npm-зависимостей не требуется. Подробнее — в [Web/README.md](Web/README.md).

## Возможности

- Все линейные размеры в миллиметрах: ввод, результаты, схемы, копирование и PDF. Уклон — в процентах, углы — в градусах.
- Отдельная высота правой и левой фары.
- Расчёт снижения луча, высоты отметок от пола и угла наклона.
- Схемы стены и хода луча сбоку.
- Копирование расчёта и сохранение PDF через диалог печати браузера; расширенная геометрия начинается с новой страницы.
- На схеме стены и в PDF у обеих фар СТГ имеет горизонтальный участок слева и подъём вправо от центра. Расчётная высота относится к левому горизонтальному участку; форма подъёма показана условно.
- Сохранение параметров и списка подготовки в localStorage браузера между посещениями.
- Проверка ввода, поддержка десятичной точки и запятой.
- Опциональная боковая поправка: выбор боковой стены слева или справа, угол автомобиля по двум расстояниям от фар, точные отметки от угла стен.
- Угол между стенами по трём сторонам произвольного треугольника; схема измерений и вид сверху.
- Проверка согласованности замеров у бамперов; длину между бамперами измерять не нужно.
- Опция «Учесть линзу за стеклом»: ввод расстояний до стекла с расчётом от линз, включая боковую поправку и PDF.

## Расчёт

```text
Снижение (мм) = расстояние (мм) × уклон (%) / 100
Высота отметки (мм) = высота центра фары (мм) − снижение (мм)
Угол вниз (°) = atan(уклон / 100) × 180 / π
Вертикальные отметки от оси автомобиля = ± половина расстояния между фарами
```

Пример: высота 700 мм, расстояние 5000 мм, уклон 1% → снижение 50 мм, отметка 650 мм от пола.

Источник формулы и подготовки: [HELLA — Headlamp adjustment](https://www.hella.com/techworld/en/technical/automotive-lighting/headlight-adjustment/). Значение уклона берётся с фары или из документации конкретного автомобиля. Начальные значения приложения — пример.

Расчёт предполагает ровную горизонтальную площадку и вертикальные прямые стены. В простом режиме автомобиль перпендикулярен передней стене. В расширенном режиме схема показывает целевые точки с учётом разворота; форму пучка и правила совмещения его опорной точки определяет производитель оптики. Приложение не измеряет свет и не калибрует адаптивные системы. Для LED, ксенона и автокорректора может потребоваться диагностический прибор.

Пределы ввода — рабочие пределы калькулятора, а не нормативные значения: расстояние 500–30000 мм; высота 100–2500 мм; уклон 0,1–5%; расстояние между фарами 200–2500 мм. Разметка ниже уровня пола отклоняется.

## Линза за стеклом

Включите «Учесть линзу за стеклом» и введите «Линза → стекло» в миллиметрах. Эта величина — **разница кратчайших перпендикулярных расстояний до передней стены**, одинаковая для обеих фар. Расстояния до передней стены вводятся от стекла; высота и расстояние между центрами — для линз. Значение по умолчанию — 0 мм; допустимый диапазон 0–1000 мм.

```text
До линзы по перпендикуляру = до стекла по перпендикуляру + поправка
Расстояние вдоль оси луча = расстояние до линзы по перпендикуляру / cos(ψ)
```

Пример без разворота: 5000 мм до стекла + 100 мм поправки = 5100 мм до линзы. При высоте линзы 700 мм и уклоне 1% снижение составит 51 мм, высота отметки — 649 мм.

Сложение выполняется **до** учёта разворота: при любом угле стекло ближе к передней стене ровно на указанную величину. При этом исходные замеры и угол автомобиля не меняются. Смещения от перпендикуляров пересчитываются для линз; отметки от угла стен остаются на тех же продольных направлениях. На схемах отмечено положение стекла и линзы. Поправка и исходные значения записываются в PDF и копируемый отчёт. При отключённой опции сохраняется прежний расчёт.

## Боковая поправка

Включите «Боковая поправка» в параметрах. Все расстояния до стен измеряются **по кратчайшему перпендикуляру к соответствующей стене**, в миллиметрах:

1. Выберите боковую стену слева или справа по ходу движения.
2. Измерьте расстояния от центров переднего и заднего бамперов до боковой стены.
3. Измерьте расстояние от центра **каждой** фары до передней стены.
4. Для рабочего способа «По треугольнику» измерьте расстояние от центра переднего бампера до передней стены. В обоих замерах переднего бампера используется одна и та же точка.
5. При необходимости включите измерение угла стен: O — их угол, A — произвольная точка на боковой стене, B — на передней. Введите OA, OB и AB. Все точки должны лежать в одной горизонтальной плоскости.

Результат: высота каждой целевой точки от пола, расстояние от угла **вдоль передней стены**, а также боковое смещение относительно перпендикулярной проекции каждой фары на стену. Влево/вправо всегда указаны по ходу движения. В PDF расширенная геометрия начинается с новой страницы.

Центры фар должны лежать на одной поперечной линии автомобиля. Расстояние между ними измеряется в горизонтальной плоскости. Если фары смещены относительно друг друга вперёд-назад, угол нельзя однозначно определить этим методом. Замеры у бамперов служат проверкой согласованности направления разворота; длина автомобиля не требуется и не вводится. Сообщение о противоречии боковых замеров сохраняется в PDF и копируемом отчёте.

В формулах `ψ` — разворот автомобиля к нормали передней стены, положительный вправо; `γ` — внутренний угол между стенами; `s` = +1 для левой стены и −1 для правой. Координата `x` направлена вправо от угла, `y` — от передней стены к автомобилю:

```text
ψ = asin((d_правой − d_левой) / ширина_между_фарами)
γ = acos((OA² + OB² − AB²) / (2 × OA × OB))
Расстояние вдоль оси луча = d_фары / cos(ψ)
Смещение по передней стене = d_фары × tan(ψ)
x_переднего_бампера = s × (d_до_боковой + cos(γ) × d_бампера_до_передней) / sin(γ)
x_пересечения_оси = x_переднего_бампера + d_бампера_до_передней × tan(ψ)
x_отметки = x_пересечения_оси ± ширина_между_фарами / (2 × cos(ψ))
Размер_от_угла = s × x_отметки
```

В этих формулах длины приводятся к одной единице измерения. Рабочий угол задаётся явным переключателем «По фарам / По треугольнику». В способе по фарам предполагается параллельность боковой стене, поэтому `γ = 90° + s × ψ`, а `x_пересечения_оси = s × d_до_боковой / sin(γ)`; расстояние от бампера до передней стены сокращается и не требуется. В способе по треугольнику используется общий расчёт выше. Сравнение показывает оба угла и их разницу независимо от выбранного способа. При неравных боковых расстояниях оценка по фарам явно помечается как условная; для предупреждения о несовпадении введённых чисел используется допуск 0,1 мм, который не является оценкой точности измерения. Ошибка необязательного треугольника не блокирует расчёт по фарам. Невозможные треугольники, геометрия за стенами и граница света ниже пола отклоняются. В расширенном режиме расстояния до стен ограничены 100000 мм. Результат чувствителен к ошибке разности расстояний от фар: нужны точные перпендикулярные замеры.

## Проверка

```sh
npm --prefix Web run build
```

19 тестов проверяют ввод, геометрию, поправку линзы, переключение методов и сохранение настроек. Команда build выполняет проверку синтаксиса и тесты. В набор входят 77 эталонных расчётных сценариев из `Web/tests/reference-fixtures.json`; проверки не требуют отдельного генератора или сборки приложения.

Браузерные проверки Playwright описаны в [Web/README.md](Web/README.md).

## Размещение и обновления в Vercel

Проект Vercel связан с `andreykeks/setcarlight`. Корневая папка — `Web`, Framework Preset — `Other`, Build Command — `npm run build`, Output Directory — `public`. Для проверок используется Node.js `22.x`, закреплённый в `Web/package.json`. Установка зависимостей отключена в `vercel.json`, переменные окружения не требуются.

Обновления: отдельная ветка → pull request → проверка Vercel Preview → слияние в `main` → автоматическая публикация Production. При неуспешных проверках новый выпуск не заменяет работающий сайт.

Пошаговая инструкция и описание настроек — в [Web/README.md](Web/README.md).
